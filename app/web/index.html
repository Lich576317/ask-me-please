快捷键取词

Ctrl+E

在飞书 / Obsidian 里选中一段文字，按这个键，它就解释你选中的那段。 中英文都认 —— 和框选那条不一样，那条只认英文。

它会临时借用一下剪贴板把你选的字读走，读完原样还回去。 剪贴板里要是图片或文件（不是文字），它就不动手，免得弄丢你的东西。

开始之前

这个工具会把识别到的笔记文字，发送给你自己配置的 AI 模型来生成解释。

  • 截屏与文字识别全部在本机完成，不外传
  • 只有识别出的文字会发给模型厂商
  • 解释过的术语和解释会保存在本机的知识库文件里，下次遇到同一个词就不再问模型
  • API Key 存在本机，请勿在公用电脑上使用
